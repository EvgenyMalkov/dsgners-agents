# Чек-лист перед сдачей
- [ ] Первая строка цепляет и понятна без контекста.
- [ ] Нет выдуманных фактов; ссылки — только реальные из задачи или статьи.
- [ ] Текст укладывается в лимит (с картинкой ≤ 1024 знаков желательно).
- [ ] Каналы взяты из списка, тексты адаптированы под каждый.
- [ ] Визуал от дизайнера прикреплён там, где он нужен.
- [ ] Нет ошибок, «ё» на месте.
