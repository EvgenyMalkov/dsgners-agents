2. Попроси графического дизайнера сделать `tg-post`: заголовок для картинки — суть статьи в 4–7 словах,
   рубрика по типу материала («Кейс», «Урок», «Мнение», «Подборка»), тему выбери на его усмотрение.
3. Структура поста:
   - строка 1 — проблема или неожиданный тезис из статьи;
   - 2–3 коротких абзаца или список пользы (без Markdown, списки через «—»);
   - имя автора, если оно есть в статье;
   - последняя строка — «Читать: <ссылка>».
4. 500–900 знаков. Добавь через draft_post с картинкой дизайнера.
