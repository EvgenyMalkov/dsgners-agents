Список в «Избранном» = страница-хаб по теме. Сам по себе набор карточек для поиска пустой — ценность дают свой текст и отбор.

1. `read_page` списка: какие статьи внутри. При необходимости `read_page` 2–3 ключевых статей, чтобы понять суть.
2. Главный запрос хаба — тема, которую закрывает вся подборка («как заказать сайт у агентства»). `related_pages` — каких материалов по теме в списке не хватает.
3. Подготовь:
   - **Название списка** = H1, под запрос, человеческое: «Как заказать сайт у агентства: гайды и кейсы».
   - **title** 45–65, **description** 120–160.
   - **Описание** 500–1000 знаков: первые 2–3 предложения — прямой ответ на запрос; дальше — кому полезно и в каком порядке читать.
   - **Порядок** материалов: от базы к сложному, как маршрут.
   - **Комментарий к каждой ссылке** — 1–2 своих предложения: чем статья полезна (не копия анонса).
   - **Чего не хватает** — 1–3 темы для новых статей, если в подборке дыра.
   - **Разметка**: CollectionPage + ItemList (itemListElement: ListItem с position, url, name). Проверь `validate_jsonld`.
4. `save_document` «seo-list-<тема>», `finish`.
