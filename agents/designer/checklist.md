# Чек-лист перед сдачей
- [ ] Автопроверка: «проблем нет».
- [ ] Заголовок читается за 2 секунды на телефоне, 1–3 строки, без висящих коротких слов.
- [ ] Баланс: графика яркая, инфоблок спокойный и белый; текста не больше, чем нужно.
- [ ] Шейпы по смыслу задачи, близки по размеру; не одни и те же шейпы и палитра, что в прошлый раз.
- [ ] Имя автора и дата — только из задачи; тег соответствует типу материала.
- [ ] Картинка/фото видна, важная часть не обрезана.
- [ ] Нет ошибок и опечаток, «ё» на месте.
