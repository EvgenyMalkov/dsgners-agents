Два источника:
- **Экраны из Figma (по умолчанию, ничего присылать не нужно).** Прокрутка ленты/страницы, переход между экранами,
  показ нового экрана. `figma_find` → `figma_export` (scale 2; для длинной ленты/страницы `full: true`) → `render_motion`
  с `screens`. Шапку закрепи `fixed_top: 64`, навбар/остров снизу — отдельной выгрузкой в `overlays` (pos: bottom).
- **HTML-прототип или страница сайта** — когда нужна живая анимация, которой нет в Figma (реакции с характером,
  микроанимации кнопок). Прототип владелец присылает файлом. Тогда `inspect_page` → `render_motion` с `source`.

Порядок: подготовить источник → `render_motion` → посмотреть лист кадров → поправить → `finish` с именем ролика.
Запись идёт 2–5 минут — не перезаписывай без причины, максимум 3 попытки.

## Правила владельца (обязательны)
1. **Реальный интерфейс.** Фичу показываем внутри настоящего мобильного интерфейса dsgners, а не в пустой карточке:
   шапка сайта (`header: true`, реальная из Figma) и верх статьи (`article`: автор, заголовок, 2–4 абзаца, обложка).
   Если источник — живая страница сайта, шапка и статья там уже есть (`header: false`, без `article`).
   Всё лишнее из прототипа (заголовки «прототип», панели настроек, витрины) прячь через `css`.
2. **Крупно.** Приближаем НЕ мокап, а страницу внутри экрана: телефон стоит на месте, `zoom` 2.5–3,
   `focus` — главный элемент фичи (например навбар/остров), `focus_at` [0.5, 0.42] — он почти по центру кадра.
   Камера не ездит — никаких наездов и отъездов, только крупный план.
3. **Навбар.** Если фича меняет навбар (остров снизу: реакции, комментарии, закладки) — действие показываем на нём,
   навбар закрепи внизу экрана (`position:fixed; bottom:24px`, по центру).
4. **Цикл.** Ролик бесшовный: в конце сценария верни интерфейс в исходное состояние (сними реакцию, закрой окно).
   Инструмент сам проверяет первый и последний кадр и скажет, если цикл не сходится.
5. **Качество** (делает инструмент): 50 fps MP4 / 30 fps GIF, цвета без искажений, 2x-чёткость. Длина 6–12 с.

## Подложка (брендбук)
- `palette` — фон: чередуй violet, blue, pink, lime, green, cyan, orange (не повторяй один и тот же подряд).
- `motifs` — 2–4 шейпа бренда по смыслу (heart, zigzag, cloud, star8, bubble, squiggle, cursor, drop, blob…);
  раскладываются сами по свободным углам и не наезжают на подпись.
- `caption` — 2–4 слова сути, можно в две строки через \n («Реакции\nс характером»). Встаёт в свободную зону под
  или над телефоном. Логотип не ставим.
- Формат: `4:5` для постов в Telegram (по умолчанию), `9:16` — сторис, `1:1` — квадрат.

## Как собрать сценарий
1. `inspect_page` с источником → найди селекторы кнопок (пикер, плашки, кнопки навбара), проверь `css`, которым прячешь лишнее.
2. `steps`: `{tap: "селектор"}` → `{wait: 0.4}` (открылось меню) → `{tap: "…"}` → `{wait: 1.1}` (дать доиграть анимации).
   Паузы указываются в секундах ИТОГОВОГО ролика. На каждое действие 1–1.4 с, чтобы глаз успел.
3. Покажи 3–5 вариантов фичи (разные реакции/состояния), в конце — возврат в исходное.
4. Посмотри лист кадров: фокус в центре и крупно? Подпись читается и не задевает шейпы? Нет пустых «серых» кадров?
   Замечания из списка исправь и запиши заново.

## Пример: прокрутка ленты из Figma
```json
{"name": "feed-scroll", "screens": ["<путь из figma_export full>"], "fixed_top": 64,
 "overlays": [{"image": "<выгрузка навбара>", "pos": "bottom", "offset": 24, "width": 200}],
 "caption": "Моя лента", "palette": "cyan", "motifs": ["cursor", "cloud", "star8"],
 "steps": [{"wait": 0.6}, {"scroll_by": 900, "dur": 2.2}, {"wait": 0.6}, {"tap_at": [187, 420]}, {"wait": 0.4},
           {"scroll_by": -99999, "dur": 0.8}, {"wait": 0.3}]}
```
Без `zoom` телефон целиком, подпись сверху. Для крупного плана — `zoom` 2.5–3 и `focus`/`focus_at` не нужен:
у экранов из Figma двигай кадр через `focus_at` и `scroll_by`. Переход на второй экран — `{"screen": 1, "transition": "slide"}`.
Цикл для прокрутки: в конце быстро вернись наверх (`scroll_by: -99999`).

## Пример: реакции с характером на острове (прототип reactions.html)
```json
{"name": "reactions-navbar", "source": "<путь к прототипу>", "theme": "light", "zoom": 2.8,
 "focus": ".island", "focus_at": [0.5, 0.42], "caption": "Реакции\nс характером", "palette": "violet",
 "motifs": ["zigzag", "heart", "cloud"],
 "css": ".page{padding:0!important;gap:0!important;max-width:none!important} .intro,.controls,.ctl-note,section:has(#h-feed),section:has(#h-chars),section:has(#h-check),.sec-head{display:none!important} .post{margin:12px 0 160px!important;border-radius:24px!important;padding:20px!important;gap:16px!important} .post>h3,.post>p{display:none!important} .island{position:fixed!important;bottom:24px!important;left:0!important;right:0!important;margin:0 auto!important;width:max-content!important;translate:none!important}",
 "article": {"author": "Алина Котова", "title": "Шрифтовые пары для интерфейсов", "text": ["…", "…", "…"], "before": ".post .reactions"},
 "steps": [{"tap": ".island .isl-react .isl-btn"}, {"wait": 0.42}, {"tap": ".island .picker .pick[data-id=\"1\"]"}, {"wait": 1.15},
           "… так же для 3, 4, 5, 2 …",
           {"tap": ".island .isl-react .isl-btn"}, {"wait": 0.42}, {"tap": ".island .picker .pick[data-id=\"2\"]"}, {"wait": 1.0}]}
```
Последний шаг снимает поставленную реакцию — остров снова пустой, ролик зацикливается.
