# ТЗ: API сайта dsgners.ru для ИИ-агентов

**Зачем.** SEO-агент готовит для статей SEO-поля (title, description, подписи к картинкам, разметку) и письма авторам
с рекомендациями. Сейчас владелец вносит это руками. С этим API после его «Ок» в Telegram всё уходит на сайт само.

**Главный принцип: API узкое.** Агенты не могут менять текст статей, удалять что-либо, видеть почту или личные
данные авторов. Только три метода ниже.

## Доступ
- Базовый адрес, например `https://dsgners.ru/api/agents`.
- Авторизация: заголовок `Authorization: Bearer <токен>`. Токен длинный, случайный, хранится на сайте в виде хеша,
  его можно отозвать и перевыпустить. Владелец вписывает его в `.env` агентов (`SITE_API_TOKEN`), адрес — в `SITE_API_URL`.
- Разрешить запросы только с IP сервера агентов (его даст владелец).
- Лимит: 60 запросов в минуту. При превышении — `429`.
- Ответы — JSON. Ошибки: `{"error": "понятный текст"}` и код 4xx/5xx.

## 1. Получить статью
`GET /article?url=<полный адрес статьи>`

```json
{
  "id": 12366,
  "url": "https://dsgners.ru/na_produkte/12366-dizayn-marafon-a-ne-sprint",
  "author": "na_produkte",
  "title": "Дизайн — марафон, а не спринт",
  "published_at": "2026-08-14T10:00:00+03:00",
  "seo": {
    "seo_title": "", "meta_description": "", "og_title": "", "og_description": "", "jsonld": ""
  },
  "images": [ {"src": "https://dsgners.ru/upload/…/1.jpg", "alt": ""} ]
}
```
`404`, если статьи с таким адресом нет. Почту автора не отдавать.

## 2. Записать SEO-поля
`PATCH /article/{id}/seo`

```json
{
  "seo_title": "до 75 знаков",
  "meta_description": "до 180 знаков",
  "og_title": "…",
  "og_description": "…",
  "jsonld": "{\"@context\":\"https://schema.org\", …}",
  "images": [ {"src": "https://dsgners.ru/upload/…/1.jpg", "alt": "…"} ]
}
```
- Все поля необязательные: что пришло — то обновить, остальное не трогать.
- `images` — только поменять `alt` у картинок этой статьи с таким `src`. Картинки не добавлять и не удалять.
- `jsonld` — проверить, что это валидный JSON; выводить в `<head>` статьи в `<script type="application/ld+json">`.
  Если шаблон уже выводит свою разметку Article (см. `docs/seo-site-template.md`), то `jsonld` из API заменяет её для этой статьи.
- **Текст, заголовок статьи (H1), обложку и автора менять нельзя** — даже если такие поля придут.
- Сохранять историю: кто/когда/что было/что стало — чтобы можно было откатить в админке одной кнопкой.
- Ответ: `{"ok": true, "changed": ["seo_title", "meta_description", "images"]}`.
- Эти поля должны быть видны и редактируемы в админке (блок «Для поисковиков»), чтобы редакция могла поправить руками.

## 3. Письмо автору
`POST /author-message`

```json
{ "article_id": 12366, "subject": "Как вернуть читателей статье «…»", "text": "до 1500 знаков, простой текст с переносами строк" }
```
Сайт сам:
1. Сохраняет письмо и показывает его автору на странице `https://dsgners.ru/messages/<id>` (видит только автор статьи
   и админы). Отправитель — «Редакция dsgners».
2. Создаёт **уведомление** автору на сайте: «Редакция dsgners: советы по статье „…“» → ссылка на эту страницу.
3. Отправляет **email** автору на его почту из профиля: тема = `subject`, в письме — текст и кнопка «Открыть на dsgners»
   (ссылка на страницу письма). Отправитель — адрес редакции, ответ на письмо уходит в редакцию.
4. Не отправляет, если автор отключил письма от редакции в настройках (нужна галочка «Получать советы редакции
   по моим статьям», по умолчанию включена) — тогда только уведомление на сайте, в ответе `"email": false`.
5. Не больше одного письма автору по одной статье за 30 дней — иначе `429 {"error": "уже писали по этой статье"}`.

Ответ: `{"ok": true, "message_id": 881, "url": "https://dsgners.ru/messages/881", "email": true}`.

## Как проверить
1. `curl -H "Authorization: Bearer <токен>" "https://dsgners.ru/api/agents/article?url=<адрес статьи>"` — приходит JSON статьи.
2. Без токена или с неверным — `401`.
3. `PATCH` с новым `seo_title` → в коде страницы статьи новый `<title>`; в админке видна запись в истории изменений.
4. `POST /author-message` на тестовую статью своего аккаунта → пришло уведомление на сайте и письмо на почту, ссылка открывает письмо.
5. В боте агентов: `/seo_fix <адрес статьи>` → «Ок» → бот отвечает «SEO-поля записаны на сайт».
